# 失败必须传染到退出码

**问题**（第三轮评审 PSD-01/07，实测复现）：merge-to-pdf 全 scripts 唯一的
`Bun.write` 让 node 运行时在全部图片 embed 完成后崩溃（PDF 不产出）；生成器
部分失败却 exit 0，下游 merge 放行缺页 deck，间隙警告只归因「删除过幻灯片」
误导排查。同型：.txt prompt 的讲稿被配对逻辑静默丢弃。

**approach**：merge-pdf.test.mjs 在纯 node 下跑真实合并（bun-ism 回归即红）；
failed_slides 非空 → sys.exit(1)；配对逻辑 .md 优先、.txt 兜底。

**落进哪里**：merge-to-pdf.ts / generate-slides.py / merge-to-pptx.ts + 两个
新测试文件。教训：**管道里每一环的失败都要传染到自己的退出码，且警告文案要
覆盖真实病因的全集——单一归因的警告是排障的路标也是陷阱。**
