# 自动判断引用制式时，猜错的那一种引用会被整体静默丢掉

## 问题

`check_proposal.py --style auto` 初版只看文献表：条目以 `[N]` 开头就按顺序编码制对账，
否则按 APA。对抗方给出三种真实写法——文献表写成 Markdown 有序列表 `1. …`、方括号被转义
成 `\[1\]`、全角 `［1］`——都让 auto 回退到 APA，正文里每一个 `[N]` 引用都不再参与对账，
孤儿引用两个方向都以 exit 0 放行。而 SKILL.md 把这个门禁描述为「一次跑完所有机械检查」，
agent 看到 exit 0 就会跳过手工核对。

## approach

- 两种制式的行内引用**都数**：同一文本里两种都有 → `mixed-citation-style` 失败；
  显式 `--style` 与正文制式不符 → `style-mismatch` 失败。猜不准时宁可失败。
- auto 按正文里占多数的制式定，不再只看文献表；文献表条目同时接受 `[N]` 和 `N.`/`N)`。
- 比对前统一全角与转义方括号。

## 结论

**一个按「检测到的类型」分派的门禁，必须对「没被选中的那一类」也有一个失败出口。**
否则检测错一次，整类输入就从门禁里消失，而且消失得无声无息——exit 0 看起来和「真没问题」
一模一样。
